# Healthcare Clinic Management System

A clinic management web application built from scratch.

## Features

- Patient management
- Doctor management
- Appointment management
- Medical records
- Prescriptions
- User roles
- Dashboard

## Technology

Frontend: Next.js + TypeScript

Backend: Python + FastAPI

Database: PostgreSQL

AI/ML: Local Python models

## Project Rules

- No copied projects
- No forked projects
- No employer/client code
- No external APIs
- No real patient data
- No API keys or secrets in source code
- AI assistance will not replace meaningful human development
